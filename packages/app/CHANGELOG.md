# Changelog

## 0.0.3

### 功能优化

1. 子任务执行过程中就可以打开思考过程查看，内容会实时刷新，不必等子任务结束。
2. 工具调用行会直接显示子任务正在进行中，点一下即可进入对应的思考过程，不用先展开详情。
3. 工具调用的一行摘要会挑选有区分度的参数展示，同一屏里多次调用同一个工具也能区分开。
4. 工具调用详情展开时不再发生宽度跳变，并带有展开动画。
5. 思考过程实时刷新时只在已经贴底时自动滚动，向上翻阅历史不会被新内容打断。

## 0.0.2

### 功能优化

1. 桌面 App 和 VS Code 插件的服务器切换体验更加一致，切换本机或远程服务器更方便。
2. 远程服务器配置支持 HTTPS，适合连接启用安全访问的 sbot 服务。
3. VS Code 插件补齐文件下载、终端连接等能力，插件内的聊天体验更完整。
4. 聊天界面、输入框和文件浏览体验进一步优化，日常使用更顺手。
5. Android 端启动失败时会显示具体错误，排查连接或运行环境问题更直接。
6. 移动端不再弹出桌面更新检查，减少无效提示。

### 修复

1. 修复桌面 App 检查到新版本时可能提示更新失败的问题。
