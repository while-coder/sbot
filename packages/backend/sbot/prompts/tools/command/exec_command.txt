Run shell commands in the session workspace, or pass an absolute workdir. Use installed command-line programs for file operations, builds, tests, and scripts. Shell syntax follows the server's platform.

Commands that continue running return a processId. Use write_stdin with that processId to read subsequent output, or pass timeoutMs at startup when you need the exit status in a single call.

Pass stdin to send text at startup and then close standard input. To stop a running command, call write_stdin with its processId and terminate=true.
