本次主要更新如下：

### 新增

1. 新增「远程 Agent 客户端」渠道，外部 IDE、调试器和 Agent 可通过 WebSocket 或 HTTP + SSE 接入，并按会话提供专用提示词、工具和附件；模型调用、对话历史与记忆仍由 sbot 统一管理。
2. 长期记忆新增全局与工作区两级作用域，项目相关知识会按 `workPath` 隔离保存和检索；管理后台可切换查看不同作用域的记忆与后台任务。
3. 新增 `remember_memory` 工具，用户明确要求记住信息时可立即加入写入队列，并准确选择全局或当前工作区；Memory Profile 还可单独配置 Selector 模型筛选相关记忆。
4. 日程新增详情查询、原子编辑和关闭操作，支持已完成、已取消、已过期等完整状态，并可在管理后台查看同步任务及失败原因。
5. 小爱渠道支持在同一渠道中接入多台音箱，每台音箱保持独立会话，回复只会播回发起对话的设备。
6. 新增 Agent 能力插件接口，可扩展静态/动态提示词、工具和回合结束处理，并控制是否向子 Agent 继承。

### 优化

1. 记忆提取改为先匹配全局与工作区目录、再由 Writer 阅读候选正文，改善大型记忆库的相关性和 Token 使用；同时优化重复合并、证据计数与搜索输出。
2. 日程同步在对话和事项过多时会分批筛选相关条目，列表使用精简预览、详情按需读取，复杂日程的识别和修改更稳定。
3. 记忆与日程后台任务提供更清晰的状态查看；失败的记忆任务可直接重试或删除记录。
4. 群聊意图过滤会参考最近对话，更容易识别依赖上下文的追问和接话；飞书群聊也会保留被 @ 成员的显示名称。
5. 小爱音箱可按名称、别名、deviceID 或 miotDID 选择，设备改名后会话仍保持连续。
6. Web、桌面 App、CLI、VS Code 插件与远程 Agent 统一消息和附件格式，文本、图片与文件在不同客户端之间传递更稳定。
7. 聊天页的智能体和会话存储选择器统一为一致的下拉交互，配置选择更清晰。

### 修复

1. 修复远程 Agent 使用 HTTP + SSE 时响应可能在实际处理完成前关闭的问题，并为错误和长时间无进展的请求补充可靠收尾。
2. 修复新记忆与现有 slug 重复时创建失败，以及无新对话的整理任务可能错误增加证据次数的问题。
3. 修复一次性或有限次数日程在正常结束、错过时间或重试失败后状态不准确的问题。
