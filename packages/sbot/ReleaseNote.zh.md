本次主要更新如下：

### 新增

1. Token 用量页新增完整分析能力：可按时间、智能体、模型、供应商和渠道筛选，并查看趋势、分布和每次调用明细。
2. 模型与 Embedding 配置会显示被哪些智能体、记忆、日程、Note 和 Wiki 引用，方便调整配置前确认影响范围。
3. 文件系统新增统一的 `move` 工具，可用于移动、重命名或复制文件和目录。
4. 子任务执行过程中就可以打开思考过程查看，内容会实时刷新，不必等子任务结束。
5. 管理后台设置页新增「停止服务」，停止接收新任务，等正在执行的智能体、记忆和事项任务完成后退出。
6. VS Code 插件新增「在编辑器中打开聊天」，可以把聊天开在编辑器标签页里，侧边栏入口保持不变。

### 优化

1. OpenAI 兼容模型接口在请求失败时会保留服务端返回的具体错误信息，排查模型配置更方便。
2. 工具调用的一行摘要会挑选有区分度的参数展示，同一屏里多次调用同一个工具也能区分开。
3. 工具调用详情展开时不再发生宽度跳变，并带有展开动画。

### 修复

1. 修复编辑智能体配置时，表单未展示的扩展配置可能被意外清空的问题。
